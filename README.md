## Pages

| Folder | Page | Content |
|--------|------|---------|
| `page1` | Home | Hero section, featured creatures, list of traditions |
| `page2` | Bestiary | Grid of 9 creatures with images, tags and short descriptions |
| `page3` | Mythologies | Six traditions and a comparison table |
| `page4` | About | Project description, how we work, purpose of the wiki |
| `page5` | Contact | Form for suggesting a story or correction |

## Project structure

```
WebProject/

├── page3/
│   ├── index.html
│   └── styles.css
├── page4/
│   ├── index.html
│   └── styles.css
└── page5/
    ├── index.html
    └── styles.css
```

Each page has its own `index.html` and `styles.css`. Pages link to each other with paths like `../page2/index.html`, so the folder structure must stay the same
